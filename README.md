# AI Workplace Productivity Assistant

## Project Overview

AI Workplace Productivity Assistant is a modern AI-powered web application designed to help professionals automate workplace tasks efficiently.

The platform combines multiple AI productivity tools into a single dashboard to improve communication, organization, and time management.

This project demonstrates:

* Practical AI implementation
* Prompt engineering
* Real-world problem solving
* Responsible AI usage
* Modern UI/UX design

---

# Features

## Smart Email Generator

* Generate professional workplace emails
* Support different tones:

  * Formal
  * Informal
  * Persuasive
* Adapt emails for:

  * Clients
  * Managers
  * Teams
* Editable AI-generated responses

---

## Meeting Notes Summarizer

* Summarize lengthy meeting notes
* Extract key discussion points
* Identify decisions made
* Generate action items
* Highlight deadlines and responsibilities

---

## AI Task Planner / Scheduler

* Generate daily and weekly schedules
* Prioritize tasks by urgency and importance
* Suggest time optimization strategies
* Improve productivity planning

# Setup Instructions

## Clone Repository

```bash
git clone https://github.com/AnatiTyuka/AI-Workplace-Productivity-Assistant.git
```

## Open Project Folder

```bash
cd AI-Workplace-Productivity-Assistant
```

## Install Dependencies

```bash
npm install
```

## Run the Project

```bash
npm run dev
```
